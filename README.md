## Fig 1. AI Powered News Website Architecture Diagram.

I developed an AI-powered news website MVP in three days. I used BeautifulSoup for parsing and Pexels API for relevant images. I implemented Continuous Delivery (CI/CD) using GitHub and Vercel for agile deployment. It pushes daily headlines to social platforms automatically using official API wrappers.

I implemented an AI powered news website in my second semester of university in Bash, Python, and JavaScript with an architecture I designed. The core of the project is a script using the Lynx browser to scrape news from Google, summarizes it with Gemini, upload the result to GitHub, and post to Tumblr. The update script ran on my PC as a job, allowing me to have live updates without dedicated hardware.
